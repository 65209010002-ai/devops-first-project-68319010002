ขั้นตอนการใช้งาน
1. เปิดโปรแกรมเว็บเบราว์เซอร์ เช่น Google Chrome หรือ Microsoft Edge
2. คัดลอก URL ของเว็บไซต์ที่ต้องการเข้าใช้งาน
3. นำ URL ไปวางในช่องค้นหาด้านบนของเว็บเบราว์เซอร์
4. กดปุ่ม Enter เพื่อเข้าสู่เว็บไซต์
5. รอให้เว็บไซต์โหลดเสร็จ จากนั้นสามารถเริ่มใช้งานระบบได้

GitHub Desktop

โปรแกรมสำหรับจัดการโปรเจกต์ Git และเชื่อมต่อกับ GitHub ผ่านหน้าจอแบบกราฟิก ช่วยให้ผู้ใช้งานสามารถจัดการไฟล์และติดตามการเปลี่ยนแปลงของโปรเจกต์ได้โดยไม่จำเป็นต้องใช้คำสั่ง Git ใน Terminal ตลอดเวลา


ความสามารถหลักของ GitHub Desktop
1. Clone Repository – ดาวน์โหลดโปรเจกต์จาก GitHub มาไว้ในเครื่อง
2. Commit Changes – บันทึกการเปลี่ยนแปลงของไฟล์
3. Push Origin – ส่งข้อมูลและ Commit ขึ้นไปยัง GitHub
4. Pull Origin – ดึงข้อมูลล่าสุดจาก GitHub ลงมายังเครื่อง
5. View History – ตรวจสอบประวัติการแก้ไขและ Commit ก่อนหน้า
6. Create Branch – สร้าง Branch สำหรับแยกการพัฒนางาน

ขั้นตอนการใช้งาน
1. เปิดโปรแกรม GitHub Desktop
2. เลือกเมนู File แล้วเลือก Add Local Repository
3. เลือกโฟลเดอร์โปรเจกต์ที่ต้องการเปิด
4. กด Add Repository
5. ตรวจสอบไฟล์โปรเจกต์ที่แสดงในโปรแกรม
6. เลือก Open in Visual Studio Code เพื่อเปิดและแก้ไขโค้ด
4. ประโยชน์ของ GitHub Desktop
- ช่วยให้จัดการโปรเจกต์ได้ง่ายขึ้น
- ลดความซับซ้อนในการใช้คำสั่ง Git
- สามารถตรวจสอบไฟล์ที่มีการแก้ไขได้
- ช่วยสำรองและแบ่งปันโค้ดผ่าน GitHub
- สามารถทำงานร่วมกับสมาชิกในทีมได้สะดวก
